## ✨ Deskripsi

Project **Sistem Manajemen Perpustakaan Kampus** merupakan program sederhana berbasis console yang digunakan untuk mengelola beberapa aktivitas perpustakaan.

Program ini menerapkan enam struktur data yang dipelajari dalam mata kuliah Pemrograman Berorientasi Objek, yaitu:

- **Array 1 Dimensi**
- **Array 2 Dimensi**
- **Array 3 Dimensi**
- **ArrayList**
- **Stack**
- **Queue**

Setiap struktur data digunakan sesuai dengan kebutuhan pengelolaan data dalam sistem perpustakaan.

---

## ⚙️ Fitur Program

### 📖 1. Lihat Kategori Buku

Menampilkan daftar kategori buku yang tersedia dalam sistem.

### 📚 2. Kelola Daftar Buku

Digunakan untuk menampilkan, menambahkan, dan menghapus data buku.

### 📊 3. Lihat Data Peminjaman

Menampilkan data jumlah peminjaman berdasarkan kategori buku dan hari.

### 🗺️ 4. Cek Lokasi Buku

Menampilkan informasi lokasi buku berdasarkan lantai, rak, dan posisi buku.

### 🔄 5. Riwayat Transaksi

Menyimpan dan menampilkan riwayat transaksi peminjaman menggunakan konsep **Stack (LIFO)**.

### 👨‍🎓 6. Antrean Peminjaman

Mengelola antrean mahasiswa yang ingin melakukan peminjaman menggunakan konsep **Queue (FIFO)**.

### 🚪 7. Keluar

Mengakhiri program.

## 🎯 Tujuan Project

Project ini bertujuan untuk:

- Menerapkan konsep struktur data dalam pemrograman Java.
- Memahami penggunaan **Array 1D, Array 2D, dan Array 3D**.
- Menerapkan **ArrayList** untuk pengelolaan data secara dinamis.
- Menerapkan konsep **Stack (LIFO)** dalam pengelolaan riwayat transaksi.
- Menerapkan konsep **Queue (FIFO)** dalam pengelolaan antrean mahasiswa.
- Menggabungkan beberapa struktur data ke dalam sebuah sistem perpustakaan sederhana.

---

## 📌 Konsep yang Diterapkan

Secara keseluruhan, sistem menggunakan struktur data sebagai berikut:

- **Array 1D** → digunakan untuk menyimpan kategori buku.
- **Array 2D** → digunakan untuk menyimpan data jumlah peminjaman berdasarkan kategori dan hari.
- **Array 3D** → digunakan untuk menyimpan lokasi buku berdasarkan lantai, rak, dan posisi.
- **ArrayList** → digunakan untuk mengelola daftar buku secara dinamis.
- **Stack** → digunakan untuk menyimpan riwayat transaksi dengan konsep **LIFO (Last In, First Out)**.
- **Queue** → digunakan untuk mengatur antrean peminjaman dengan konsep **FIFO (First In, First Out)**.

## 📝 Kesimpulan

Project **Sistem Manajemen Perpustakaan Kampus** berhasil menerapkan beberapa struktur data dalam sebuah program berbasis **Java Console**. Struktur data yang digunakan meliputi **Array 1D, Array 2D, Array 3D, ArrayList, Stack, dan Queue**, yang masing-masing diterapkan sesuai dengan kebutuhan sistem.

Melalui project ini, konsep struktur data dapat diterapkan dalam pengelolaan kategori buku, daftar buku, data peminjaman, lokasi buku, riwayat transaksi, serta antrean mahasiswa. Dengan demikian, project ini menjadi penerapan sederhana dari materi yang telah dipelajari dalam mata kuliah **Pemrograman Berorientasi Objek**.
